# Version 1.0.0 (changes from ballot)

## High Level Summary of changes

* Expanded overview section
* Added additional operations for testing if a server conforms to a client's expectations and returning subsets of a CapabilityStatement
* Added necessary details to incomplete sections of the specification
* Refinements to the query language syntax
